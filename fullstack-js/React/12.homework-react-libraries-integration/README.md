# React Libraries Playground

A small React + TypeScript application demonstrating the integration of three specialized libraries:

- **React Icons** — icons used throughout the interface.
- **React Toastify** — success, warning, and error toast notifications.
- **React Idle Timer** — detects user inactivity and updates the activity status.

## Requirements

- Node.js 18 or later
- npm

## Installation

```bash
npm install
```

## Development

```bash
npm run dev
```

Vite will print the local development URL in the terminal.

## Production build

```bash
npm run build
```

The production files are generated in the `dist` directory.

To preview the production build locally:

```bash
npm run preview
```
