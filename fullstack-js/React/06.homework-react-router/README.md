# React Router

## Description

A simple React application demonstrating client-side routing using React Router, React, TypeScript and Vite.

The application consists of three pages accessible through a shared navigation layout:

- **Home:** Displays the home page.
- **About Us:** Displays the about page.
- **Contacts:** Displays the contacts page.

The project demonstrates route configuration with `createBrowserRouter`, navigation using `NavLink`, nested routes and page rendering through `Outlet` and `RouterProvider`.

## Features

- **Client-Side Routing:** Configure application routes using `createBrowserRouter`.
- **Navigation:** Navigate between pages using `NavLink` without full page reloads.
- **Shared Layout:** Use a common layout for navigation and page content.
- **Nested Routes:** Render child route components inside the layout using `Outlet`.
- **Route Rendering:** Provide the configured router to the application using `RouterProvider`.
- **TypeScript:** Use TypeScript with React components.

## Installation and Usage

**Prerequisites:** [Node.js](https://nodejs.org/) and npm.

1. Clone the repository:

   ```bash
   git clone https://github.com/604vadym/604vadym.github.io.git
   ```

2. Navigate to the project directory:

   ```bash
   cd 604vadym.github.io/fullstack-js/React/06.homework-react-router
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in the terminal.
