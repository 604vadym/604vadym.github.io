# Showcase App (Slider / Audio Player / Shop)

### Prototype-based OOP & ES6 Classes

An educational JavaScript architecture project exploring a music showcase, interactive
slider, audio player and shop built around finite state machines and object-oriented design.

The project includes two implementations based on related architectural concepts, using prototype-based OOP and ES6 classes.

## Implementations

### [on-prototypes-oldschool-goa-trance](./on-prototypes-oldschool-goa-trance/)

A prototype-based OOP implementation focused on inheritance, composition, component interaction, finite state machines, custom events and manager-based architecture.

### [on-classes-platipus](./on-classes-platipus/)

An ES6 class-based implementation developed as a further evolution of the project, reworking the same architectural concepts using JavaScript classes, static contracts, inheritance and polymorphism.

## Purpose

The project was created as an educational architecture study and portfolio project. It is based on the same application concept as an earlier procedural JavaScript implementation, but uses a fundamentally different architectural approach based on object-oriented design.

The original procedural implementation can be found [here](../10-homework-slider-pure-js-on-fuctions/).

The project explores how a relatively complex interactive application can be structured around reusable components, managers, event-driven communication, finite state machines and object-oriented design.

The two implementations provide an opportunity to compare prototype-based and class-based approaches while keeping the underlying application concept closely related.
