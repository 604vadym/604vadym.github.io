# Project Vitest

This project contains a test suite built with **Vitest**.

## 🛠️ Technologies Used

- **JavaScript (ES Modules)** (`"type": "module"`)
- **Vitest** (`^5.0.1`) — Fast testing framework
- **Happy DOM** (`^20.14.5`) — DOM environment for testing
- **@vitest/coverage-v8** (`^5.0.1`) — Code coverage provider

---

## 🚀 Installation & Setup

To set up the project, open your terminal at the root of the repository and run:

### 1. Navigate to the project folder

```bash
cd fullstack-js/JavaScript/12-homework-unit-testing-jest-vitest/project-vitest
```

### 2. Install dependencies

Make sure you have [Node.js](https://nodejs.org) installed, then run:

```bash
npm install
```

---

## 🧪 Running Tests

You can execute the test suite or check code coverage using the following commands:

### Run tests in watch mode

```bash
npm test
```

### Run tests once and generate coverage report

```bash
npm run test:coverage
```

The coverage report will be generated using the `v8` provider and will output results in text and HTML formats.
