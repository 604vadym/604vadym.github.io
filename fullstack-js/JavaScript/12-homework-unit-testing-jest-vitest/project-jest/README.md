# Project Jest

This project contains a test suite built with **Jest**.

## 🛠️ Technologies Used

- **JavaScript (ES Modules)** (`"type": "module"`)
- **Jest** (`^30.5.2`) — Testing framework
- **Babel** — Used for configuring ES Modules support in the Jest environment

---

## 🚀 Installation & Setup

To set up the project, open your terminal at the root of the repository and run:

### 1. Navigate to the project folder

```bash
cd fullstack-js/JavaScript/12-homework-unit-testing-jest-vitest/project-jest
```

### 2. Install dependencies

Make sure you have [Node.js](https://nodejs.org) installed, then run:

```bash
npm install
```

---

## 🧪 Running Tests & Coverage

You can execute the test suite or generate code coverage reports using the following commands:

### Run all tests

```bash
npm test
```

### Run tests and generate code coverage report

```bash
npm run test:coverage
```

This command runs the test suite and generates a detailed HTML coverage report. The static files are compiled into the project's coverage directory.
