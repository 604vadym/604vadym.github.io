# Procedural JavaScript — Asura Tribute

An educational JavaScript project exploring the implementation of a complex interactive music showcase using a procedural programming approach.

The application combines an interactive slider, audio player and shop, with user interactions coordinated through procedural application logic. The project focuses on implementing the required functionality and ensuring reliable and predictable application behaviour within a procedural architecture.

## Project evolution

This project represents the original procedural implementation of the slider and music showcase. It serves as the starting point for a subsequent architectural experiment.

The application is built around functions, event handlers and coordinated application logic. The primary focus of this version was to implement the required functionality and establish the complete interaction model.

The project was later redesigned using prototype-based OOP and subsequently migrated to ES6 classes, with a stronger separation of responsibilities, component-level managers, custom event communication and local finite state machines.
